About EduManage

A simple, thoughtful way to organize student information.

E
BUILT FOR LEARNING

Education, organized.

EduManage is a student management web application designed to make basic academic record management clear and accessible. It is built using HTML, CSS and JavaScript, and can be hosted for free with GitHub Pages.

HTML5CSS3JavaScriptGitHub Pages
Demo project note
Student records are saved in this browser using local storage. They are not stored in a central database and will not automatically sync across devices. Avoid entering sensitive real student information.
